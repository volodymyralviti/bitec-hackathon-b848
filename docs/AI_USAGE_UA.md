# Як ми використали ШІ

ШІ-асистент Codex допомагав створювати код, автоматизовані тести, документацію
та авторські чернетки двох навчальних сценаріїв. Команда визначила українську
мову, Angular/NestJS, окремі DSL та детермінований engine, анонімне голосування
й обмеження щодо персональних і службових відомостей. Автоматизовані перевірки
підтверджують структуру та поведінку програми, а не юридичну правильність матеріалу.

Обидва кейси — вигадані освітні адаптації за мотивами CIDS: №16 про закупівлю
обладнання та №1 про професійну консультацію всупереч очікуванням керівництва.
Тексти створено власними словами; повний посібник не перевидано. Першоджерела
не були доступні в цьому checkout для незалежного прочитання. Атрибуція,
редакція й умови використання потребують підтвердження командою.

У JSON чесно збережено `aiAssisted=true`, `demoOnly=true` та review `draft`.
Джерела позначено `unverified`. Немає фактичного експертного sign-off або
підтвердження відповідності чинному українському законодавству. Реальний рецензент
має перевірити факти, правові питання, педагогічні компроміси й записати докази review.
Тестовий reviewer stub перевіряє лише захист API на synthetic даних.

Під час проходження ШІ не викликається: метрики та відкладені наслідки визначають
явні JSON-правила й pure TypeScript engine. Випадковості або прихованого
LLM-оцінювання немає. Чотири показники описують модель наслідків управлінського
вибору; вони не оцінюють особистість і не призначені для командирського звіту.

Застосунок не має runtime AI Copilot, зовнішнього LLM-з’єднання або надсилання
голосів/навчальних маршрутів моделям. Повна політика події щодо ШІ не надана:
жодний провайдер тут не оголошується дозволеним. Не можна передавати персональні,
службові чи операційні дані в авторинг, зовнішні інструменти або моделі.

Люди відповідають за фінальне review коду й контенту, перевірку прав і джерел,
підтвердження актуальних правил події та рішення про публікацію. Ця записка —
короткий опис фактичного використання ШІ, не експертний висновок чи гарантія безпеки.
